# Community code of conduct

This applies to issues, pull requests, reviews, discussions and other project spaces.

- Be respectful, specific and constructive. Critique ideas and code without personal attacks.
- Welcome people with different backgrounds and experience; explain context without belittling.
- Do not harass, discriminate, threaten, dox or publish another person's private information.
- Respect consent, confidentiality and maintainers' time. Avoid spam and repeated unwanted contact.

Maintainers may request changes, remove harmful content or limit participation when needed.
Responses should be proportionate and consider context. For community incidents, contact a
maintainer privately through a contact method they publish on their GitHub profile, or use
GitHub's reporting tools. Do not repost sensitive details publicly while seeking help.

For a security vulnerability, use the private reporting instructions in [SECURITY.md](SECURITY.md).
